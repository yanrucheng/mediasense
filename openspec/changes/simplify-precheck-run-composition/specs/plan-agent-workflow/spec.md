## ADDED Requirements

### Requirement: Plan can request local preparation through an ordinary Run
The Plan Agent SHALL own the judgment that a selected scope needs different preparation. It SHALL express that request through the public Run contract with complete requirements, while PreCheck SHALL own bounded preparation and compression. No application-specific category SHALL become a core service branch or Profile entity.

#### Scenario: Existing evidence is sufficient
- **WHEN** public expansion and current evidence resolve the material planning question
- **THEN** the Agent may continue the existing Work without creating another Run

#### Scenario: Preparation settings need a local change
- **WHEN** the Agent needs a different compression setting for T within S
- **THEN** it reads the reusable preparation value, resolves its intended selection and submits a complete ordinary start request

### Requirement: Plan preserves justified decisions in a new Result-bound Work
An existing Work SHALL remain bound to its original Result. After deliberate new preparation, the Agent SHALL use existing public inspect/create/update/review operations to continue in a new Work. It SHALL distinguish source correspondence from evidence equivalence and semantic validity, and SHALL NOT transfer old Result-local references or Human confirmation blindly.

#### Scenario: Unaffected prior judgment still has support
- **WHEN** verified source correspondence and inspected new evidence preserve the judgment's actual basis
- **THEN** the Agent may retain the judgment and preferences in the new Work without restarting the entire semantic discussion

#### Scenario: New grouping changes a judgment's evidence
- **WHEN** an old representative relationship or relevant observation changes
- **THEN** the Agent reevaluates the affected claim and uses the current Plan confirmation flow for the new exact organization

#### Scenario: Correspondence cannot be proven
- **WHEN** resolve reports unproven for a source needed by the old organization
- **THEN** the Agent retains its uncertainty or investigates and does not manufacture a migrated reference or accepted candidate
